# Relax Digital Web Application

A full-stack web application with React (Vite) and Node.js / Express backend with MongoDB and JWT-based authentication.

## Project Structure
- `/frontend`: React + Vite frontend application with Tailwind CSS and Lucide icons.
- `/backend`: Node.js, Express, MongoDB Mongoose API with dual authentication and role-based access.

## Quick Start

### 1. Backend Setup
```bash
cd backend
npm install
# Configure your environment variables in .env (see .env.example)
npm run dev
```

### 2. Frontend Setup
```bash
cd frontend
npm install
npm run dev
```
